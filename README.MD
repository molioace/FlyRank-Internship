# FlyRank Internship

This repository contains my assignments and projects completed during the FlyRank Internship program.

The internship includes two tracks:

- **Backend AI Engineering** — focusing on building AI-powered backend systems, APIs, LLM integrations, and practical AI engineering workflows.
- **General AI Fluency** — covering fundamental AI concepts, tools, and best practices for effectively working with AI technologies.

Each track is organized into its respective assignments, with code, documentation, and implementations developed throughout the internship.
